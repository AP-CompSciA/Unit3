# Computer Programming

## Unit 3: Methods and Strings

In this unit, students learn how to use and create methods in Java. They begin by exploring the `String` class and its built-in methods, learning how methods accept arguments and return values. Students then apply these ideas by creating their own methods in custom classes, including understanding `public` and `private` methods, preconditions and postconditions, and `static` methods. The unit concludes with methods from the `Math` and `Integer` libraries and introduces common errors that can occur when working with methods and objects.

### Topics

* **Strings and Methods**

  * What is a method?
  * Calling methods on `String` objects
  * Method arguments and return values
  * `length()` and `charAt()`
* **More String Methods**

  * `substring()`
  * `indexOf()`
  * `equals()`
  * `compareTo()`
  * `toUpperCase()` and `toLowerCase()`
  * Understanding `StringIndexOutOfBoundsException`
* **Custom Class Methods**

  * Creating methods
  * Parameters and return values
  * `public` vs. `private`
  * Preconditions and postconditions
* **More Custom Class Methods**

  * Reviewing method design and use
  * `static` methods
  * Understanding `NullPointerException`
* **Java Libraries**

  * Methods from the `Math` and `Integer` classes
  * Using library methods and their arguments/return values
